# rpl2026-kelompok-3

## Deskripsi
Repository ini digunakan untuk mengerjakan praktikum Rekayasa Perangkat Lunak (RPL) tahun 2026. Proyek ini dikerjakan secara berkelompok menggunakan Git dan GitHub.

## Tujuan
- Mempelajari penggunaan Git dan GitHub.
- Memahami penggunaan branch untuk pengembangan fitur secara paralel.
- Melatih kerja sama tim melalui kolaborasi kode.
- Menggabungkan fitur menggunakan Pull Request.

## Teknologi
- Python
- Git
- GitHub

## Alur Kerja
1. Mengambil repository dari GitHub.
2. Berpindah ke branch `develop`.
3. Membuat branch fitur masing-masing.
4. Mengembangkan dan menguji program.
5. Melakukan commit dan push.
6. Membuat Pull Request menuju `develop`.
